# 任务脉络骨架（示例，改成你自己的）

> 脉络是活的：每完成 4 个节点加密一轮；每条支最多领先完成进度 2 个节点。

## 出题规则

1. 在架制：上一题未验收，不出新题。
2. 域轮转：M（数学/物理）→ A（算法/代码）→ AI（人工智能）→ E（英语）。
3. 每题必含五件：背景（≤2行）/ 要做什么（≤5条）/ 验收（可判定）/ 6h 口径 / 前置节点。
4. 卡死 90 分钟可查资料（账本记「用了外援」）；直接看答案 = 看答案过关，换等价题再来。
5. 周日不出新题：自己给自己出题。

## 主干（bank.py 里的 W0 四题）

- M1 岭回归的四种面目（几何/贝叶斯/数值/判决）
- A1 并查集的摊还账（实现/证明/退化实测）
- AI1 LayerNorm + Dropout 手撕（含数值梯度自检）
- E1 Orwell《Politics and the English Language》精读（英文摘要+反驳）

## W1 分叉候选（主干全过后展开）

- M：数值线（稀疏三角求解/填充实测 → 消去树 → 低秩压缩）｜概率线（方差削减 → MCMC）｜物理线（费米估算 → 费马原理）
- A：经典线（LRU/LFU/一致性哈希 → KMP/后缀数组）｜系统线（计算器语言 → 迷你 KV 存储）
- AI：复现线（论文表格数字 → attention 变体消融）｜理论线（Adam 手推 → 双下降）
- E：学术线（技术报告英文版 → 套磁信）｜原版书线（Flatland → Feynman）

## 交叉节点候选

- E×A：把摊还证明改写成英文讲义
- A×M：给数值实验做基准 + 分析缓存效应
- AI×M：用复现的模型跑压缩对比
